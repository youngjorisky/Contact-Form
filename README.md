# Frontend Mentor - Contact Form Solution

This is a solution to the [Contact Form Challenge](https://www.frontendmentor.io/challenges/contact-form--sS4R9J6E) on Frontend Mentor. Frontend Mentor challenges help you improve your coding skills by building realistic projects.

## 🧠 Overview

### The Challenge

Users should be able to:
- Complete the form and see a success message upon successful submission.
- Receive validation messages if:
  - A required field has been missed.
  - The email address format is incorrect.
- Complete the form using only their keyboard.
- Have inputs, error messages, and the success message announced by a screen reader.
- View the optimal layout for the interface depending on the device’s screen size.
- See hover and focus states for all interactive elements.

## 🧱 Built With

- Semantic **HTML5** markup  
- **CSS Grid** and **Flexbox**  
- **JavaScript (DOM validation)**  
- Mobile-first workflow  

## ⚙️ Key Features

- Real-time input validation for first name, last name, email, and message.
- Displays inline error messages and red borders for invalid fields.
- Shows a success message box upon valid submission.
- Responsive layout for both mobile and desktop.
- Accessible design (keyboard and screen reader friendly).

## 🚀 What I Learned

While working on this project, I improved my understanding of:
- JavaScript form validation logic using regular expressions.
- DOM manipulation (`insertAdjacentElement`, `closest`, and dynamic error handling).
- Applying conditional CSS states for accessibility.
- Structuring and styling a clean responsive layout.
